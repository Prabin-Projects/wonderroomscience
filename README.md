# The Wonder Room

The website for **The Wonder Room**, an animated YouTube channel that turns big "what if?" questions into short stories with real science. Doz, a very curious kid, and Pip, a know-it-all flying robot, test wild ideas and find out what would actually happen.

- **Website:** https://wonderroomscience.netlify.app
- **YouTube:** https://www.youtube.com/@WonderRoomScience

## What's on the site

- **Episodes:** every episode, newest first, with a link to watch it on YouTube.
- **Sources:** each episode has a page listing the studies and references behind its facts.
- **Corrections desk:** spotted a factual mistake in a video? Report it on the website. Every report is checked against the video and its sources, and confirmed mistakes are fixed.

New episodes come out every Tuesday and Saturday.
